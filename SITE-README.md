# 1000 unread emails — website

Open `Website.dc.html` (or rename it to `index.html` for GitHub Pages).

## First-time setup
In `poems.js`, set `repo` to your GitHub repo, e.g. `'alejandra/1000-unread-emails'`.

## Add a poem
Upload the image to `assets/poems/`. The site lists that folder automatically and the counter updates.
Optional: add its description in `poems.js` under `POEM_ALTS` (file name → text). It is read aloud by screen readers.

## Resources
Upload PDFs to `resources/` with these exact names:
- `facilitators-guide_en.pdf` (English)
- `facilitators-guide_es.pdf` (Spanish)
- `slide-deck.pdf`
- `participant-booklet.pdf`
- `poem-card.pdf`

## Files the site needs
`Website.dc.html`, `support.js`, `poems.js`, `assets/` (logo + poems), `resources/`.
